# Pocketchat

Pocketchat is a chat assistant you talk to in your browser: you type a question, press Send, and Pocketchat
answers.

This repository holds a clickable mockup of Pocketchat. Its answers are written in advance, so the page
shows how a conversation with Pocketchat feels while the real assistant is being built.
